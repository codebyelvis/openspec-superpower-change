## ADDED Requirements

### Requirement: Bounded compact instruction routing

The Router SHALL use short selection metadata and contextual reference loading.
It SHALL preserve all Gate 0 facts, existing OpenSpec/protected boundaries,
Non-negotiables, behavior evidence, required checks and profile-appropriate
Review PASS. It SHALL NOT create a new mode, profile or governance framework.

For obvious local reversible Direct Changes outside every protected boundary,
the Router SHALL allow one-line Gate 0, minimum edits, scoped verification and
inline diff/self-review. It SHALL NOT universally select Plan, Preflight, full
TDD cycles, domain discovery, Handoff, independent multi-agent Review or Learning
Closeout for that subset. This bounded method-selection exception replaces
unconditional TDD/Preflight selection only for that subset; it SHALL NOT
override selected method gates or an explicitly required contract check.

For unchanged approved continuation it SHALL reuse existing authorization and
canonical state without replaying satisfied gates. Learning entry SHALL depend
on correction/Review history or explicit archive/distillation, preserving all
mandatory promotion triggers and blocks. Other completion rules SHALL remain
owned by the existing Completion Contract.

#### Scenario: Non-behavioral micro edit

- **WHEN** a typo, formatting, comment or non-contractual documentation edit is obvious and local
- **THEN** one-line Gate 0 leads to minimum edit, relevant required verification and inline Review
- **AND** no implementation-reference bundle, full TDD, Plan, Preflight or automatic learning audit is required

#### Scenario: Local restoration outside protected boundaries

- **WHEN** a small internal fix restores defined behavior entirely within its current blast radius without touching any protected boundary
- **THEN** compact routing applies without a mandatory full TDD or Preflight cycle
- **AND** cause evidence, behavior regression evidence, required checks, compact slice signoff and Review PASS remain required

#### Scenario: Approved unchanged continuation

- **WHEN** approved safe work remains and scope, risk and contract are unchanged
- **THEN** execution continues from canonical state without repeated approval or rereading the whole governance set
- **AND** outstanding required Plan, Preflight, tests, evidence and Review gates still apply

#### Scenario: OpenSpec boundary is present even without high risk

- **WHEN** a change meets any existing OpenSpec boundary, including new functionality or workflow routing
- **THEN** the Router requires the existing OpenSpec proposal and explicit approval before implementation
- **AND** calling the task small, local, reversible or low-risk does not authorize a shortcut

#### Scenario: Major skill cleanup

- **WHEN** cleanup changes trigger scope, request routing, OpenSpec/Superpowers boundaries, evidence signoff or completion-claim rules
- **THEN** a specific strictly validated OpenSpec change requires explicit user approval before implementation
- **AND** backup, required forward-tests, validators, Review and applicable runtime sync remain mandatory

#### Scenario: Required checks and scoped failures

- **WHEN** the change class or approved contract explicitly requires a validator or broader suite
- **THEN** that check runs even when additional testing is limited by blast radius
- **AND** unrelated failures are recorded as OUT_OF_SCOPE_PREEXISTING_DEBT without silently waiving required checks or expanding the fix

#### Scenario: Completion and learning remain gated

- **WHEN** behavior evidence or profile-appropriate Review is missing, stale, FAIL or BLOCKED
- **THEN** the Router cannot claim completion
- **AND** correction/Review history or an explicit archive request still loads Learning Closeout and preserves its mandatory promotion rules

#### Scenario: Model and selection independence

- **WHEN** Astra, Pi, Claude Code or another agent reads the same instructions
- **THEN** identical task and authority facts select identical protected boundaries
- **AND** ordinary questions, standalone wording/read-only diff Review and valid handed-off batches retain their existing non-Router or companion routes
