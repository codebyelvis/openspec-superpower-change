# Change: Align Native Agent Governance Consumption

Author: elvis. Revision: draft-v1. Date: 2026-10-10.

## Why

Three advisory reviews identify inconsistent native instructions around
Preflight, Superpowers entry, plan placement, and review delivery. The existing
four-target portable copies are equal; replacing their installer would not fix
these instruction conflicts. A product-level parity result also does not qualify
an alternate account, launcher, native configuration, or running session.

The user wants Codex-led content reuse without repeatedly editing several
agents. This change makes the existing authority and consumption boundaries
explicit, while preserving both skills and the existing synchronization chain.
Static conflicts are observed; seven-entry behavioral equivalence is unproven.

## What Changes

- Scope CCG-004 to the existing compact LOCAL Direct Change exception. External
  compact execution, standard/strict work, multi-slice work and protected effects
  retain their required standalone gates.
- Make CCG-014 expose the already-defined ordinary-question/standalone-advisory
  exception. Keep Router-first selection and every selected child's full gates.
- Require plans when applicable before execution; preserve user/project and
  immutable contract paths over generic native directory defaults.
- Define chat advisory, explicitly saved advisory and bound external evidence
  as separate delivery contracts. File persistence re-enters Router classification;
  it does not create a formal assignment or authorize canonical transitions.
- Document actual-entry qualification, content consumers, launcher identity and
  the boundary between portable sync and native adaptation.
- Add artifact-owned negative regression checks and behavioral forward proof
  for these boundaries through the existing validation infrastructure.
